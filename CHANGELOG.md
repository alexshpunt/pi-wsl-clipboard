# Changelog

## 0.2.0 - 2026-08-24

- Support native Windows alongside WSL.
- Skip `wslpath` when the extension runs on native Windows.
- Keep image-first paste and text fallback behavior unchanged.

## 0.1.0 - 2026-08-24

- Add WSL clipboard bridge for Pi.
- Paste Windows clipboard images and text with `Ctrl+V`.
- Add PowerShell and `pwsh.exe` clipboard fallbacks.
